# Timer Clock

A simple timer app built with React.

It has two modes:
- Countdown timer: Set a time and count down to zero.
- Stopwatch: Start from zero and count up.

The app also shows the current date and time in the top-right corner.

## Features

- Countdown mode with:
  - Set timer (minutes/seconds, optional hours)
  - Start, pause, stop, reset
  - Sound + visual alert when time is up
- Stopwatch mode with:
  - Start from 0
  - Pause, stop, reset
  - Milliseconds display
  - Automatically shows hours after 1 hour
- Live current date and time display

## Required Languages and Technologies

- HTML
- CSS
- JavaScript (ES6+)
- React.js
- Node.js (to run locally)
- npm (comes with Node.js)
- Vite (build tool)

## Setup

1. Clone the repository:
```bash
git clone https://github.com/tjagadeeswarreddy/timer-clock.git
```

2. Move into the project folder:
```bash
cd timer-clock
```

3. Install dependencies:
```bash
npm install
```

4. Start the development server:
```bash
npm run dev
```

5. Open the local URL shown in terminal (usually `http://localhost:5173`).

## Build for Production

```bash
npm run build
```

## Preview Production Build

```bash
npm run preview
```
